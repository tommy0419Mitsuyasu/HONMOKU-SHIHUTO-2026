# 本牧市民プール シフト管理システム 🏊

本牧市民プールのアルバイトスタッフ（100名以上）向けのシフト管理アプリケーションです。ランニングコストを完全無料で運用できるアーキテクチャを採用しています。

## 🌟 特徴

- **完全無料の運用**: Next.js (Vercel) + Supabase (Free Tier) により、月額0円で稼働
- **デモモード内蔵**: データベースの設定なしでも、すべての機能をブラウザ上で即座に体験可能
- **労働基準法の自動チェック**: 18歳未満（高校生）スタッフの「深夜労働禁止」「1日8時間超過」「週40時間超過」を自動でブロック
- **直感的なタイムライン**: ガントチャート形式で、誰がいつ出勤するか、人数が足りているかを一目で把握
- **Aqua Dark デザイン**: プールや水を連想させる爽やかなダークモードUI（グラスモーフィズム・アニメーション採用）

## 🚀 使い方（デモモード）

Supabaseの設定をしなくても、内蔵のモックデータを使用してすぐに動作を確認できます。

1. **依存関係のインストール**:
   ```bash
   npm install
   ```

2. **開発サーバーの起動**:
   ```bash
   npm run dev
   ```

3. **ブラウザでアクセス**:
   http://localhost:3000

## 💻 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **スタイリング**: Vanilla CSS (CSS Custom Properties) + グラスモーフィズム

- **認証**: React Context (デモ用) / Supabase Auth (本番用)

## 🏗️ 画面構成

### 管理者機能 (`/admin`)
- **ダッシュボード**: 本日の出勤人数、合計労働時間、概算人件費、週間コスト推移グラフ
- **タイムライン**: 時間帯別のシフトガントチャート、人数過不足ヒートマップ
- **承認管理**: シフトの承認・却下、取消依頼の処理
- **スタッフ管理**: スタッフ情報（時給、高校生フラグ等）の登録・編集

### スタッフ機能 (`/staff`)
- **ホーム**: 今月の勤務時間・見込み収入、今後のシフト一覧
- **シフト提出**: シフト登録（入力中にリアルタイムで労働基準法をチェック）
- **マイシフト**: 自身のシフト一覧、未承認シフトの編集・取消、承認済シフトの取消依頼

## 🚢 本番デプロイ手順

1. **Supabase プロジェクトの作成**:
   - [Supabase](https://supabase.com/)で新規プロジェクトを作成
   - `supabase/schema.sql` を実行してテーブルとRLSポリシーを作成

2. **環境変数の設定**:
   ルートディレクトリに `.env.local` を作成し、以下の値を設定:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your-project-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
   ※環境変数が設定されると、自動的にデモモードからSupabase連携モードに切り替わります。

3. **Vercelへのデプロイ**:
   - VercelにGitHubリポジトリを連携してデプロイ
   - Environment Variablesに上記2つのキーを設定

## 📝 労働基準法チェックロジック

`src/lib/validators.js` にて以下のチェックを実装しています（18歳未満のスタッフが対象）:
1. **深夜業の禁止**: 22:00〜翌5:00の勤務は登録不可（労働基準法第61条）
2. **1日8時間の制限**: 既存のシフトも含め、同日の合計労働時間が8時間を超える場合は登録不可
3. **週40時間の制限**: 月曜日〜日曜日の1週間での合計労働時間が40時間を超える場合は登録不可
